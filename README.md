# Demons-Souls-Ultrawide-Mod-for-KytyPS5-SuperMedo-version


A patch for the PS5 remake of Demon's Souls on the KytyPS5 emulator.
Gameplay fills a 3440x1440 screen, wider on both sides, without stretch.
The HUD stays 16:9 and centered.

This folder does not include the game or the emulator.

## You need

- Windows 10 or 11
- A 3440x1440 monitor. The patch is built for that size.
- A Windows build of KytyPS5 that has kyty_emulator.exe and run-windows.ps1
  (https://github.com/chenxiao07/KytyPS5, the Releases page)
- Your own unpacked game folder for title PPSA01341, version 01.007.000.
  That folder contains eboot.bin and sce_sys. Another game version will not match.

## Install

1. Unzip this folder anywhere.
2. Double-click Install.bat.
3. Choose the KytyPS5 folder, then the game folder.
4. A desktop shortcut named "Demon's Souls Ultrawide" is created.

## Play

Use that shortcut, or double-click Play.bat.
Close kyty_emulator first if it is already open.
Do not turn on the emulator's "Keep 16:9 (black bars)" option. That is a different mode and is not this patch.

## What it does not change

The game files and the save are left alone. Uninstall by deleting this folder
and the desktop shortcut. The copy of the patch placed in the emulator's
patches folder can be deleted too. It is only used when Play is started.

## Why I Made This

I made this mod because I genuinely love Demon's Souls and the incredible work Bluepoint Games put into its remake.

I believe PC gamers should have the opportunity to enjoy this game on their own computers, provided they have legally purchased a copy of the game.

Bluepoint created something exceptional, especially visually, and I think experiencing it on a PC, with the possibilities of higher resolutions and ultrawide displays, can make that work even more noticeable and appreciated.

This project is simply my small contribution to making that experience possible.

## Development and AI Transparency

I want to be transparent about how this mod was created.

100% of the code was generated by AI using Cursor. I did not write the code myself.

My contribution was the idea, the direction of the project, and something AI cannot do for me: testing the results by actually playing the game.

I tested the mod from a gamer's perspective, identified visual issues, and provided feedback to guide further improvements.

This project is an example of what can happen when AI-assisted development meets a genuine passion for a game. I may not have written the code, but I knew what I wanted the experience to look and feel like.
