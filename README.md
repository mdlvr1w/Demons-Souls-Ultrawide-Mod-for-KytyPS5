# Demon's Souls ultrawide

A patch and a launcher for the PS5 remake of Demon's Souls on [KytyPS5 v20261013](https://github.com/chenxiao07/KytyPS5/releases/tag/v20261013). On a screen wider than 16:9, gameplay fills the width without stretch. The interface stays 16:9 and centered.

This repository does not include the game or the emulator. The game files are not modified.

The patch matches title `PPSA01341`, version `01.007.000`, on that Kyty release. Another version will not line up.

## Download

The launcher is ready to run from the [1.2.0 release](https://github.com/mdlvr1w/Demons-Souls-Ultrawide-Mod-for-KytyPS5/releases/tag/v1.2.0). Unzip it and start `DemonsSoulsLauncher.exe`. Leave `ultrawide-3440x1440.json` and `codex_ui_vulkan.dll` in that same folder.

## You need

- Windows 10 or 11
- [KytyPS5 v20261013](https://github.com/chenxiao07/KytyPS5/releases/tag/v20261013) for Windows, with `kyty_emulator.exe` and `run-windows.ps1` in the same folder
- Your own unpacked game folder for that title and version. It contains `eboot.bin` and `sce_sys`
- The .NET 8 SDK, only if you build the launcher yourself. The downloaded launcher does not need it

The launcher lists the resolutions of the primary display that are 16:9 or wider. A 16:9 choice fits the picture and leaves the patch off. A wider choice widens the world and keeps the interface centered. 1920×1080 and 3440×1440 stay in the list. The [1.1.0 release](https://github.com/mdlvr1w/Demons-Souls-Ultrawide-Mod-for-KytyPS5/releases/tag/v1.1.0) is the previous centered-interface build. The [1.0.0 release](https://github.com/mdlvr1w/Demons-Souls-Ultrawide-Mod-for-KytyPS5/releases/tag/v1.0.0) is the earlier interface fix.

## Build

Skip this if you downloaded the release.

From this folder:

```
dotnet publish launcher/DemonsSoulsLauncher.csproj -c Release
```

Run `DemonsSoulsLauncher.exe` here:

```
launcher\bin\Release\net8.0-windows\win-x64\publish\
```

The patch and `codex_ui_vulkan.dll` are copied into that folder next to the exe. Leave the three together.

## Play

The first time, choose the Kyty folder and the game folder, then choose Save and run.

Settings are split into General, Picture, Camera, and Shaders.

- **Language.** The same list Kyty uses. English (United States) is the default.
- **Picture.** A resolution of 16:9 or wider. The render slider scales the 3D picture from 50% to 100%. The window and the interface stay full size. At 100% the game uses the full height of the resolution you picked.
- **Camera.** Page Up moves the follow camera farther. Page Down steps back toward the original. The original distance is as close as it gets, and four steps is as far as it goes. The chosen step is saved and applied the next time the launcher sees the game. If the game is already on a farther step, that step is kept and Page Up will not add another four. Both keys can be changed.
- **Shaders.** Precompile once for this version of the game. One cache covers 16:9, ultrawide, and the render slider. A cache Kyty already built is recognized.
- **Manage savegames.** Export and import. Both wait until the game is closed.

Play stays disabled while `kyty_emulator` is already running.

The launcher also corrects the inventory item preview, and it applies the camera distance, while the game is running. Those two are part of the launcher, so start the game from there.

## What it does not change

The game files and the save stay where they are. Removing the mod is deleting this folder. Nothing is copied into the game.

The opening logos are left as the game shows them. The interface, including its labels and highlights, moves as one picture.

## Why I made this

I made this mod because I genuinely love Demon's Souls and the incredible work Bluepoint Games put into its remake.

I believe PC gamers should have the opportunity to enjoy this game on their own computers, provided they have legally purchased a copy of the game.

Bluepoint created something exceptional, especially visually, and I think experiencing it on a PC, with the possibilities of higher resolutions and ultrawide displays, can make that work even more noticeable and appreciated.

This project is simply my small contribution to making that experience possible.

## Development and AI transparency

I want to be transparent about how this mod was created.

100% of the code was generated by AI using Cursor. I did not write the code myself.

My contribution was the idea, the direction of the project, and something AI cannot do for me: testing the results by actually playing the game.

I tested the mod from a gamer's perspective, identified visual issues, and provided feedback to guide further improvements.

This project is an example of what can happen when AI-assisted development meets a genuine passion for a game. I may not have written the code, but I knew what I wanted the experience to look and feel like.
